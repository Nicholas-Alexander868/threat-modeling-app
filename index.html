01 System overview

        
A React single-page frontend collects customer support conversations and calls a backend API that orchestrates Azure OpenAI for response generation, Microsoft Graph for account and ticket lookups, Redis for session caching, and PostgreSQL for persistent conversation and ticket storage. Authentication flows through Azure AD via Microsoft Graph OAuth.

Prompt Injection via Customer Input

            
Critical

          

          
An attacker embeds adversarial instructions in a chat message to override system prompts, exfiltrate context, or trigger unintended tool calls against Microsoft Graph.

          

            ATT&CK T1059
            ATLAS AML.T0051
            OWASP LLM LLM01:2025
            NIST 800-53 SI-10
          

        


        

          

            
Excessive Agency via Graph API Scopes

            
High

          

          
Overly broad OAuth scopes let the model-driven agent perform write actions (ticket updates, mailbox access) beyond what a support flow requires.

          

            OWASP LLM LLM06:2025
            NIST 800-53 AC-6
          

        


        

          

            
Session Token Leakage via Redis

            
High

          

          
Session tokens cached in Redis without encryption or TTL enforcement can be harvested if the cache layer is exposed or compromised.

          

            ATT&CK T1552
            OWASP API API2:2023

Attack path

      
User submits a crafted chat message → React UI forwards raw text to API backend → backend passes message into the model context with insufficient isolation → model executes injected instruction, potentially invoking a Graph API tool call or leaking prior context.
